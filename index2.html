Introduction

Calccedo is a calculation engine framework library based on Java language and in the future it will support all programming languages to help developers for building applications that need complex mathematical operations, Calccedo is not just framework library, it is work as interperter and act as AI engines

Install

Install using Apache Maven

<!-- adding dependency --> <dependency> <groupId>com.github.ibrahim1hero1</groupId> <artifactId>calccedo</artifactId> <version>1.0-SNAPSHOT</version> </dependency> <!-- adding sonatype Nexus repository --> <distributionManagement> <snapshotRepository> <id>ossrh</id> <url>https://oss.sonatype.org/content/repositories/snapshots</url> </snapshotRepository> <repository> <id>ossrh</id> <url>https://oss.sonatype.org/service/local/staging/deploy/maven2</url> </repository> </distributionManagement>

Install using jar and add it to project class path

Features
First Release on 2/2/2017
  • very fast in calculation
  • support multi-line operations
  • you can trace each step during calculation process
  • you can override main calculation method like (initValidation,optimizeFormula,calculate) to add enhance code you want
  • work as interpreter and act as AI engines
  • handle unstructured operations like 3(5+2/4)/15sin(60/3(4%2(5(6/5)+12/4)/5))
  • enable developers to add custom operands as a constant like Sin(30)=0.5
  • enable developers to add Illegal custom operands by assign it to Infinity like Tan(90)=Error
  • you can say calccedo is my best

import com.precious.calccedo.handlers.CalccedoHandler; /** * * @author Ibrahim */ public class TestCalccedo extends CalccedoHandler{ public TestCalccedo(){ super.enableDeepTrace(true); } public static void main(String [] args){ TestCalccedo calccedoHandler = new TestCalccedo(); String formula = "1+5+sin(30)+20+70+80+90"; String result = calccedoHandler.calculate(formula); System.out.println(result); } }

Add new CustomOperand to calccedo

sometimes you need to add custom operand as a constant like Sin(30)=0.5 and because calccedo works only with Radians Degree
if you run Math.sin(30) in Java JDK standard it it will return 1.444444449 but in Algebra Math it should return 0.5
calccedo offers four overloaded methods to add custom operand as a constant to ignore standard result that Java JRE produce

important!
Custom operand you will add should be 3 char like: Sin - pio - akw >> akw(50) = 0.5
I know it is restricted!, but Smart developer can deal with that
Calccedo-v2 will release soon :)

addCustomOperand(String customOperandName,int quoteNumber,double value); addCustomOperand(String customOperandName,double quoteNumber,double value); addCustomOperand(String customOperandName,int quoteNumber,Object object); addCustomOperand(String customOperandName,double quoteNumber,Object object); important!
it is not allowed: to add subset of custom operand that added before
if you add sin(30)=0.5 , it is not allowed to add asin(30)=50
because asin is subset of sin word which added before

This is problem ? Noooooooo
there are more solution for that, Smart developer can deal with it
anyway I'm working now in calccedo-v2, and will solve this issues

Adding Sin(30) to calccedo as a custom operand constant Sin(30)=0.5
import com.precious.calccedo.handlers.CalccedoHandler; /** * * @author Ibrahim */ public class TestCalccedo extends CalccedoHandler{ public TestCalccedo(){ super.enableDeepTrace(false); super.addCustomOperand("Sin",30,0.5); super.addCustomOperand("Sin",30.0,0.5); } public static void main(String [] args){ TestCalccedo calccedoHandler = new TestCalccedo(); String formula = "Sin(30)"; String result = calccedoHandler.calculate(formula); System.out.println(result); } }
Adding Tan(90) to calccedo as an Illegal custom operand Tan(90)=Error
import com.precious.calccedo.handlers.CalccedoHandler; import com.precious.calccedo.handlers.Infinity; /** * * @author Ibrahim */ public class TestCalccedo extends CalccedoHandler{ public TestCalccedo(){ super.enableDeepTrace(false); super.addCustomOperand("Tan",90,Infinity.class); super.addCustomOperand("Tan",90.0,Infinity.class); } public static void main(String [] args){ TestCalccedo calccedoHandler = new TestCalccedo(); String formula = "Tan(90)"; String result = calccedoHandler.calculate(formula); System.out.println(result); } }
